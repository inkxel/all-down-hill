# ALL DOWN HILL

A 3D endless snowboarding game in a single self-contained HTML file — procedural terrain, day/night cycle, weather, and no assets.

**Play:** https://inkxel.github.io/all-down-hill/

## Controls

| | Desktop | Mobile |
|---|---|---|
| Carve | `A` / `D` or `←` / `→` | Tilt the device (or drag the lower half) |
| Jump | Hold `SPACE` to charge, release to launch | Hold to charge, release to launch |
| Backflip | Hold `SPACE` while airborne | Hold while airborne |

Land a flip clean for a score multiplier. Hit a tree, a rock, or the snow at a bad angle and you start over.

## Built with

Three.js from CDN. Everything else — terrain, trees, rocks, ramps, sky, audio — is generated at runtime.
